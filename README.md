# same-app-every-framework

YouTube「さつきのOSS研究室」の Web フレームワーク検証シリーズで使うコードです。
**同じアプリを各フレームワークで作り、同一条件で測る**ためのリポジトリです。

## 何を作るか

各フレームワークにつきデモを**二種類**作ります。

### 1. 共通デモ (比較する)

「OSSリポジトリ ミニ検索」— 検索・言語フィルタ・お気に入りだけの1画面アプリ。

- データは `shared/repos.json` (20件・固定値)。通信なし・毎回同じ結果
- 見た目は `shared/app.css` を全実装で共有。**実装ごとに変えません**
  — 完成画面はどの実装でもピクセル単位で同じになります。
  「見た目当てクイズ」が成立しないことが、条件を揃えた証明です。
  違いはコードの行数・転送量・読み込みの過程に出ます

### 2. 特徴デモ (比較しない)

そのフレームワークが公式に売りとして掲げる機能を**1つだけ**見せる小さなデモ
(`<framework>/specialty/`)。得意分野が違うものを一列に並べないため、比較対象にはしません。

## 測るもの (共通デモのみ・全実装共通)

| 指標 | 取り方 |
|---|---|
| 本番ビルドの JS 転送量 | ビルド成果物の JS を gzip したバイト数の合計 |
| 依存パッケージ数 | lockfile 基準の実体数 |
| 初回ビルド時間 | クリーンな状態から本番ビルド完了まで |
| 開発サーバ起動時間 | コマンド実行からブラウザで表示されるまで |
| 初期プロジェクトの行数 | 公式スキャフォールドが吐くソース行数 |

- 同一マシン・同一 Node・同一パッケージマネージャで、**1回だけ測ります** (やり直しなし)
- 測定は章ごとに行うため、**章をまたぐ数字は測定日が異なります** (各結果に明記)
- 結果は `RESULTS.md` に記録します

## スクリーンキャプチャ

動画で使った実物のキャプチャ (静止画・アニメGIF・mp4) を
[docs/captures/](./docs/captures/README.md) に置いています。
全実装の初期表示・操作後の画面が同一になることも、ここで確認できます。

## 方針

- 数字の優劣で結論を出しません。「何と引き換えにその数字か」をセットで扱います
- 他所のベンチマーク点数は使いません。ここにある数字はすべて自前の実測です
